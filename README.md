# Alpha SIGNature PC END (public install mirror)

Source of truth: private repo `SilkyP9/Alpha_SIGNature` (`pc-end/`).

## Run on Windows

1. Install Node.js 20+ (or use portable Node under `tools/node`)
2. Clone or download this repo
3. `npm install` then `npm run dev`
4. Open http://localhost:8080

See `INSTRUCTIONS_PC_END.md` once the full tree is synced.
